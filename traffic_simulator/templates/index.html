ℹ How it works: Every HTTP request to this server — regardless of endpoint or method — automatically produces a structured JSON log entry appended to traffic_simulator/logs/access.log. Sensitive query parameters (passwords, tokens, API keys) are automatically redacted. You can also send requests from curl, httpx, Postman, or any HTTP client targeting http://127.0.0.1:8001.

Stage 2 (future) will connect this log stream to the SENTINEL AI detection pipeline.
